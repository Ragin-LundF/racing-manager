# Pinewood Derby Break-Beam Gate CAD

OpenSCAD sources and print files for the U-frames that hold the infrared
break-beam sensors (Adafruit 2167) of the two-lane pinewood derby track, plus
the electronics housing for the ESP32. All dimensions are in millimetres.

**Use v3 for new prints.**

| Version | Description | Documentation |
|---|---|---|
| [v3](v3/) (current) | Two glued half-shells per frame with staggered dovetail joints, sensors clamped in a 1 mm seat, 40 mm thick lower arm, printed M5 bolt passages for mounting on metal angles, a separate foot for the inclined start ramp, and a housing that docks with wedge ramps. Ready-to-print STLs for left and right, assembly guide as PDF in English and German. | [v3/README.md](v3/README.md) |
| [v1](v1/) | Original design: square 20 mm profile with recessed cable channels and slide-in or clip-on covers, sensors loaded from the outer channel side, glue-on electronics housing. Start frame in three keyed sections, finish frame in one piece. | [v1/README.md](v1/README.md) |

An intermediate v2 (first half-shell design) was only test-printed and is
superseded by v3.
